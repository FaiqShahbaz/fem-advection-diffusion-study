# Raw experiment records

Files are grouped by experiment name, UTC timestamp and process identifier. A run normally has a JSON measurement file, a terminal transcript and a manifest identifying its code, inputs and environment. Source snapshots or Git commits identify the numerical implementation used.

The final report uses the spatial, temporal, accuracy-cost, selected-trajectory and selected-cost studies. Earlier construction, interpolation and pairwise comparisons support their verification. Unsuccessful spatial/Rana attempts and the finer-mesh Jacobi cap are retained and identified in the processed summaries.

Raw measurements are not edited during report cleanup or plotting. Fresh reruns create new records. [The reproduction guide](../../docs/reproducibility.md) explains how to check the saved data and how to run new experiments.
